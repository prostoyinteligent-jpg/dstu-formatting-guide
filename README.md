# 📘 Гайд з оформлення студентських робіт (ДСТУ + вимоги ВНЗ)

Повний посібник для оформлення курсових, дипломних та магістерських робіт в Україні (2026).

## Основні вимоги до оформлення

| Параметр | Значення |
|----------|----------|
| Шрифт | **Times New Roman** |
| Розмір шрифту | **14 pt** |
| Міжрядковий інтервал | **1.5** |
| Абзац | **1.25 см** |
| Поле ліве | **30 мм** |
| Поле праве | **10–15 мм** |
| Поле верхнє / нижнє | **20 мм** |
| Вирівнювання | по ширині |

## Структура роботи

1. **Титульний аркуш**
2. Завдання (якщо передбачає кафедра)
3. Анотація / Реферат (для дипломних)
4. **Зміст**
5. **Вступ**
6. Основна частина (розділи 1, 2, 3...)
7. **Висновки**
8. **Список використаних джерел**
9. Додатки

## Типові помилки, через які знижують бал

- Неправильні поля або інтервал
- Відсутність абзаців або неправильний розмір
- Список літератури не за ДСТУ 8302:2015
- Нема посилань у тексті або вони не відповідають списку
- Занизька унікальність
- Заголовки не виділені / неправильний регістр
