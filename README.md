# 📘 Гайд з оформлення студентських робіт (ДСТУ + типові вимоги ВНЗ)

Повний посібник з оформлення курсових, дипломних та магістерських робіт в Україні.

## Основні вимоги (найбільш поширені)

### Шрифт і розмір
- Основний текст: **Times New Roman 14 pt**
- Заголовки: 14 pt, напівжирний
- Міжрядковий інтервал: **1.5**
- Абзац: **1.25 см**

### Поля сторінки
- Ліве: 30 мм
- Праве: 10–15 мм
- Верхнє: 20 мм
- Нижнє: 20 мм

### Нумерація сторінок
- Внизу по центру або верху праворуч
- Титульна сторінка зазвичай без номера (але враховується в загальну кількість)

### Структура роботи
1. Титульний аркуш
2. Завдання (якщо є)
3. Анотація / Реферат
4. Зміст
5. Вступ
6. Основна частина (розділи)
7. Висновки
8. Список використаних джерел
9. Додатки (за необхідності)

## Список літератури (ДСТУ 8302:2015)

Приклади оформлення див. у файлі `examples/`.

## Типові помилки, через які знижують оцінку

- Неправильні поля / інтервал
- Відсутність абзаців
- Неправильне оформлення списку літератури
- Занизька унікальність
- Відсутність посилань у тексті
